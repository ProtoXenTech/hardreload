How HardReload+ gives you immediate clean-slate testing without opening DevTools.

Direct Tabs API Protocol Revalidation

Unlike normal browser refresh (which serves 304 Not Modified from disk cache), HardReload+ leverages chrome.tabs.reload(id, { bypassCache: true }). This instructs Chrome's network process to completely bypass memory and disk caches across all stylesheets, scripts, and iframes.

// Native Manifest V3 bypass invocation
await chrome.tabs.reload(activeTab.id, { bypassCache: true });

Subdomain Isolation

Strict host-only cookie and storage filtering. Wiping sub.example.com will never invalidate sessions or cookies on example.com.

✓ Host-Only Origin Enforced

DNR Cache Killer

Manifest V3 dynamic rules match exact requestDomains, stripping If-None-Match and injecting no-cache headers on every request.
