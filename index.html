Engine Architecture

Four targeted mechanisms built specifically for modern browser environments.

Protocol-Level Cache Bypass

Uses native chrome.tabs.reload(id, { bypassCache: true }). Forces byte-level revalidation of HTML, scripts, stylesheets, and iframe resources directly in Chrome's network process.

Surgical Storage & Service Worker Purge

Combines in-frame script execution and browsingData.remove({ origins: [origin] }). Wipes localStorage, sessionStorage, IndexedDB, and unregisters active service workers without affecting other open tabs.

Strict Subdomain Separation

Cookies and storage on sub.example.com and example.com are treated as separate partitions. Purging one domain will never log you out of the parent domain or sibling hosts.

DeclarativeNetRequest Cache Killer

Manifest V3 dynamic rules matching exact requestDomains. Automatically removes If-None-Match and injects no-cache, no-store on all outbound requests.

Installation Guide

Load the unpacked extension in Chrome, Edge, or Brave in under 30 seconds.

1

Download or Locate Extension Folder

Use the local directory in this repository or download the pre-packaged archive.

Download hard-reload-plus.zip
2

Enable Developer Mode

Navigate to chrome://extensions in your address bar and switch on the Developer mode toggle.

3

Click "Load unpacked"

Select the directory /home/sajol/Server/Tool/hardreload/extension. The HardReload+ icon will appear in your toolbar.
