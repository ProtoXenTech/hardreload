Engine Architecture

Why HardReload+ outperforms native browser shortcuts

Chrome's native DevTools hard reload requires DevTools to be docked and open. HardReload+ provides instant, background-level purging with zero friction.

Direct Tabs API Reload

Uses the native chrome.tabs.reload(id, { bypassCache: true }) protocol to force byte-level network re-validation across all sub-resources and frames.

BrowsingData Partition Wiper

Surgically removes disk cache and memory cache scoped exclusively to the active tab's origin without nuking other unrelated open tabs.

Full Client Storage Cleanup

Injected execution script flushes window.localStorage, window.sessionStorage, unregisters active Service Workers, and deletes IndexedDB schema partitions.

DeclarativeNetRequest Cache Killer

Applies dynamic Manifest V3 rules that strip conditional headers (If-None-Match) and injects Cache-Control: no-cache, no-store on every outgoing request.

Automated Tab Reload Loop

Chrome Alarm-backed countdown timer with real-time toolbar badge counter. Keeps dashboards, live logs, or test harnesses refreshed automatically.

Full Customization & Context Menu

Context menus anywhere on the page for one-click right-click purging, plus deep preferences for click actions and granular purge toggles.

Quick Setup

How to Load HardReload+ in Chrome

Takes less than 30 seconds. Works on Chrome, Edge, Brave, and Opera.

1

Download and Extract Extension Archive

Download the pre-packaged zip or use the extension/ folder directly from this repository.

Download hard-reload-plus.zip
2

Open Chrome Extensions & Toggle Developer Mode

In your Chrome address bar, open chrome://extensions and switch on the Developer mode toggle in the top-right corner.

3

Click "Load unpacked" and Select Folder

Click the Load unpacked button and select the extracted folder (or /home/sajol/Server/Tool/hardreload/extension). HardReload+ will appear in your extensions bar immediately!
