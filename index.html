Engine Architecture

Engineered for clean slate precision

HardReload+ combines native Chrome Tabs protocol, DeclarativeNetRequest, and DOM-isolated scripting.

Tabs API Bypass

Forces network re-validation via native chrome.tabs.reload(id, { bypassCache: true }) across all sub-resources and frames.

Partitioned Wiper

Surgically removes cache and storage scoped exclusively to the active tab's origin without nuking other unrelated open tabs.

Client Storage Eraser

Injected execution script flushes window.localStorage, window.sessionStorage, unregisters active Service Workers, and deletes IndexedDB schema partitions.

Quick Setup

How to Load HardReload+ in Chrome

Takes less than 30 seconds. Works on Chrome, Edge, Brave, and Opera.

1

Download and Extract Extension Archive

Download the pre-packaged zip or use the extension/ folder directly from this repository.

Download hard-reload-plus.zip
2

Open Chrome Extensions & Toggle Developer Mode

In your Chrome address bar, open chrome://extensions and switch on the Developer mode toggle in the top-right corner.

3

Click "Load unpacked" and Select Folder

Click the Load unpacked button and select the extracted folder (or /home/sajol/Server/Tool/hardreload/extension). HardReload+ will appear in your extensions bar immediately!
